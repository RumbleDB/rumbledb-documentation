# In VS Code

We have a plugin for VS code that includes RumbleDB, providing additionally syntax highlighting, code completion, visual static typing, and many nice features to explore. It is available [here](https://marketplace.visualstudio.com/items?itemName=RumbleDB.jsoniq-vscode). It is also available on Open VSX [here](https://open-vsx.org/extension/RumbleDB/jsoniq-vscode).&#x20;
