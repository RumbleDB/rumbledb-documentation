# In jupyter notebooks

The Python edition of Rumble can be used to directly write JSONiq and XQuery queries in Jupyter notebook cells thanks to the %%jsoniq and %%xquery magics. This is explained [here](../writing-jsoniq-queries-in-python/writing-queries-directly-in-jupyter-notebook-cells.md). You first need to install the library as described [here](as-a-pip-package.md).
